## 2. 构建规范契约（2026-09-13）

### 根 `Directory.Build.props`（全解决方案生效，csproj 可覆盖）

| 设置 | 值 | 说明 |
|---|---|---|
| `LangVersion` | `latest` | 全库使用最新编译器特性 |
| `SuppressTfmSupportBuildWarnings` | `true` | 压制 ~66 条 "package doesn't support net8.0-windows" 噪音（官方属性；真实 CS/分析器告警不受影响） |
| `AnalysisLevel` | `latest-recommended` | 显式启用 SDK 10 建议分析器集（非 `latest-all`，避免告警洪流） |
| `EnforceCodeStyleInBuild` | `true` | .editorconfig 代码风格规则在构建时强制 |

> Nullable 刻意不放在根 props：它是各工程的自主决策（vendored 三产代码保留自身设置）。

### `.editorconfig` CA 规则分级策略

`latest-recommended` 全量建议集会触发 ~2600 条告警，已在 `.editorconfig` 中按价值分级：

- **suggestion**：性能微优化、命名风格、现代 API 建议（IDE 可见、不阻断构建）。
- **none**：纯噪音（下划线命名、文化/格式化类）。
- **warning（保留）**：VSTHRD 线程规则、正确性相关规则。
- **目标**：全解决方案构建**零警告**。新增代码若触发未分级的 CA 规则，先评估价值：
  高价值（资源/线程/安全）→ 修复；低价值 → 追加到 `.editorconfig` 分级段并注明理由。

## 3. 算法硬约束与文档同步机制

**规则**：以下每一条都是"改错会导致现场角度/坐标错乱且难以察觉"的硬约束。
修改前必须读对应的代码注释；修改时必须**同步更新**注释与本文档登记项。

| # | 硬约束 | 登记来源 |
|---|---|---|
| 1 | 角度检测模型**只产出翻转信号**（头尾消歧），角度数值一律用掩码主轴世界角 + OffsetAngle | `DetectionRecordService`、`RecipeViewModel.Inference.cs` |
| 2 | 方向偏移比使用**长轴投影分量**而非总距离（避免离轴特征误判） | `AngleDetectionProcessor` |
| 3 | 角度模型特征居中退化时，**回退掩码路径**做消歧 | `DetectionRecordService` |
| 4 | 翻转信号优先级：**二维码 → 角度模型 → 特征池** | `DetectionRecordService` |
| 5 | 产品与特征质心均用 **OBB 中心**；角度 = 产品质心→特征质心向量的 atan2 | `HeadTailFeaturePool` 等 |
| 6 | 角度规范域 **(-180, 180]**，未知哨兵 `-9999`；经 `AngleTracker.Normalize` / `ToVGT.ToRobotAngle` 统一 | 全链路 |
| 7 | 自定义协议：单接收器、段条件独立于无码策略、UDP 无连接（IP 直连，不用域名）、协议名不得与 VGT/LL 冲突 | `ProtocolSettingsViewModel`、`ProtocolTemplateRenderer` |

**同步流程**（新增算法决策时）：
1. 在代码实现处写 `REVIEW(YYYY-MM-DD):` 或带 `2026-xx-xx` 前缀的注释，说明"为什么必须这样"。
2. 若属于上述硬约束类别，在本文档第 3 节登记一行，并在 `docs/knowledge/` 对应清单（如 `头尾判定算法改进清单.md`）补充背景。

## 4. 生命周期与线程约定（拆分后不变）

- `HomeViewModel`：单例（DI 注册），`Dispose` 带超时等待后台任务；主循环线程 → UI 线程切换一律经 `Dispatcher.BeginInvoke`（VSTHRD001 已禁用）。
- `RecipeViewModel`：由配方列表长期持有，**不随窗口关闭 Dispose**（二次打开复用）；真正销毁仅由 `RecipeManageViewModel` 触发。
- 跨线程集合（`ObservableCollection`）修改必须回到 UI 线程；后台推理结果用 `ConfigureAwait(false)` + 显式 `Dispatcher` 封送。
