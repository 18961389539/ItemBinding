# SOP 模板：换配方作业

> 使用说明：本模板为框架版，【现场补充】标记处需按实际产线填写。
> 完善后删除本说明框，并让 AI 助手记录一份异常案例（如曾发生过换配方漏步骤导致的异常）。

## 前置条件

- 【现场补充】当前订单完成/中断确认
- 已登录账号具备管理员权限（切配方需管理员）
- 新配方已在配方页创建并配置完毕（检测阈值/标定/灰度判向按新产品调好）

## 操作步骤

1. 停止供料/确认线上无在制品
2. 配方页选择新配方 → 确认切换
3. **等待预测器重载完成**（切换后日志出现重载完成记录；重载期间会跳帧，属正常）
4. 【现场补充】首件确认流程（试拍/人工核对检测结果）
5. 恢复供料，观察主页丢帧率状态条确认稳定

## 风险与注意

- 切配方后跟踪器清空（编码器差分估计与角度锁定重置），首帧若恰逢丢帧不影响后续
- 预测器重载期间（约数秒）到达的帧会被跳过——不要在此期间恢复供料
- 【现场补充】本产线历史换配方异常案例（详见异常案例库）

## 异常处理

- 模型加载失败 → 检查模型文件与 EdgeDetection 配置
- 【现场补充】其他异常处理步骤
