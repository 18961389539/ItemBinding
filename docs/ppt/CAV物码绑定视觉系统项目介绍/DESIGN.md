# DESIGN · CAV 物码绑定视觉系统 · 对外项目推介

> 风格路线：**通用设计原则 + 用户选定的「A · 科技深蓝」预览卡**。
> 未命中学术 / 咨询 / 红金政务任一预设分支 → 本文件即本项目设计宪法，逐页生成严格对照。

---

## 1. 画布与母版（具体 px）

画布 **1280 × 720**，页面 padding **左右 72px / 上下 28px**（安全区宽 1136，高 664）。

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 28–128px | 100px | 页面主标题 38px bold，色 `#E8EEF6`；左上角 4px 竖条强调 `#2E7FE0`，标题左对齐，起点 x=72 |
| **B · 内容区** | 128–652px | 524px | 一切卡片、图表、SVG、截图；禁止挤占 A/C 区 |
| **C · 页脚条** | 652–692px | 40px | 左侧项目名 `CAV 物码绑定视觉系统`（14px，`#4A6480`）+ 右侧页码 `NN / 16`（14px，`#4A6480`），统一左/右对齐位置 |

- 封面 / 章节扉页 / 结束页不套用 A/B/C 三区，采用自定义版式；四张章节扉页之间结构必须完全一致。
- B 区内容底部边界 **652px**，任何固定高度累加后不得超过该值。
- 背景：每页底色 `#0B1B2B`；右下角固定一枚 8% 不透明的 `#2E7FE0` 同心圆环（L3 纹样），全篇位置一致。

## 2. 颜色系统（4 个 hex + 中性）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **主色 · 深墨蓝（背景）** | `#0B1B2B` | 页面底色、大色块、章节扉页底、卡片底（`#12293F` 为卡片层） |
| **主强调 · 电光蓝** | `#2E7FE0` | 标题竖条、关键流程节点、图表主轴、L1 图形主轮廓 |
| **辅色 · 青绿** | `#48C9B0` | 次要数据系列、成功态、链路中的"已就绪"节点 |
| **强调色 · 琥珀** | `#F2B33D` | 只出现在视觉焦点：巨型数字、核心结论数字、Hero 页焦点描边 |
| **中性 · 文本** | `#E8EEF6`（主）/ `#8FA9C4`（次）/ `#4A6480`（页脚/辅助线） | 正文、注释、边框 |

### 2.1 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色（深墨蓝） | 55–70% | 背景与卡片底 |
| 辅色（青绿） | ≤ 20% | 次级流程、标签、图标底 |
| 强调色（琥珀） | ≤ 10%；Hero 页可达 15% | 仅巨型数字与核心结论 |
| 中性（文本/线） | 剩余 | 文本、分隔线、页脚 |

**节奏**：Hero 页（01/06/10/16）强调色 12–18%，留白 40–50%；Supporting 页（其余）强调色 ≤ 5%，留白 20–28%。第 12 页允许强调色占比最高（约 18%，聚焦耗时数字）。

### 2.2 渐变与半透明

- 主渐变：`linear-gradient(135deg, #2E7FE0 0%, #48C9B0 100%)` —— 仅用于章节扉页色带、Hero 页焦点描边。
- 卡片渐变：`linear-gradient(180deg, rgba(46,127,224,0.14) 0%, rgba(11,27,43,0) 100%)` —— 卡片顶部微光。
- 半透明策略：卡片底 `rgba(18,41,63,0.85)`；辅助线 `rgba(232,238,246,0.10)`；装饰同心圆 `rgba(46,127,224,0.08)`；SVG 节点未激活态 `fill-opacity 0.35`。
- 封面底图上叠 `rgba(11,27,43,0.55)` 蒙版 + 左侧 `linear-gradient(90deg, rgba(11,27,43,0.96) 0%, rgba(11,27,43,0.30) 70%)`，保证文字可读。

## 3. 字体系统

| 层级 | 字号 | 字重 | 行高 | 字距 | 字体 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 76px | bold | 1.15 | 2 | 微软雅黑 |
| 章节大字 | 66px | bold | 1.1 | 4 | 微软雅黑 |
| 巨型数据/锚点 | 84–108px | bold | 1.0 | -1 | Consolas（数字与单位分离） |
| 页面主标题 | 38px | bold | 1.3 | 1 | 微软雅黑 |
| 副标题/卡片小标题 | 24px | bold | 1.4 | 0.5 | 微软雅黑 |
| 正文 | 20px | regular | 1.65 | 0 | 微软雅黑 |
| 小字注释/标签 | 16px | regular | 1.5 | 0.5 | 微软雅黑 |

- 巨型数字一律走 **Consolas**，与正文形成明显字重反差。
- 全篇字体家族仅 **2 套**：微软雅黑（中文/标题/正文）+ Consolas（数字、代码、代号）。
- 禁止所有页面仅用系统默认无衬线而不声明。

## 4. 信息密度门禁

| 页面类型 | 本页正文字数下限 | 主视觉 B 区占比 |
| :--- | :--- | :--- |
| 封面 | 40 | ≥ 60%（全幅底图） |
| 目录 | 120（合计） | — |
| 内容页（单主题/图证） | 200 | ≥ 30% |
| 卡片组页 | 每卡 ≥ 100 | — |
| 图表页 | 80 + 解读 | ≥ 45% |
| 章节过渡 | 35 | ≥ 40% |
| 结束页 | 25 | — |

- 常规内容页留白上限 **35%**；Hero 页 40–50%（留白围绕焦点元素，禁止均匀稀薄）。
- 卡片填充率 ≥ 85%；卡片尾部元素（标签条 / 结论条）用 `marginTop: 'auto'` 钉底。
- 同一行兄弟卡片的三段（图标/标题/正文/尾部）y 轴必须对齐，误差 ≤ 16px。
